INTRODUCTION                                                  *sql-lens-intro*

sql-lens.nvim shows PostgreSQL/MySQL/SQLServer/SQLite/MongoDB query execution
plans inline in your buffer as you type SQL.

Features:
- Real-time EXPLAIN as you type (debounced)
- PostgreSQL, MySQL, SQL Server, SQLite, MongoDB support
- Smart hints: missing indexes, high cost, row estimate drift
- Inline virtual text + floating detail window
- Dynamic database selection (dbname optional)
- Table Explorer: browse tables/collections
- Query History: persistent, filterable by connection
- Auto-completion: table & column names via nvim-cmp
- .env credential loading

==============================================================================
SETUP                                                         *sql-lens-setup*

Install with your package manager, then call setup(): >lua

  require("sql-lens").setup({
    connections = {
      { name = "local", type = "postgres",
        host = "localhost",
        user = "postgres", password = "secret",
        dbname = "mydb" },  -- optional: omit to pick later via :SqlLensDB
    }
  })
<

Requirements:
- Neovim >= 0.9
- `psql` / `mysql` / `sqlcmd` / `sqlite3` / `mongosh` CLI in PATH
- nvim-treesitter with SQL parser (optional, improves detection)

COMMANDS                                                   *sql-lens-commands*

:SqlLensConnect                                            *:SqlLensConnect*
    Open connection picker.

:SqlLensDisconnect                                      *:SqlLensDisconnect*
    Disconnect current buffer's connection.

:SqlLensToggle                                              *:SqlLensToggle*
    Enable/disable inline analysis.

:SqlLensExplain                                            *:SqlLensExplain*
    Manually trigger explain on current statement.

:SqlLensFloatDetail                                    *:SqlLensFloatDetail*
    Show full plan in floating window.

:SqlLensUse {name}                                            *:SqlLensUse*
    Set active connection by name.

:SqlLensRun                                                    *:SqlLensRun*
    Execute SQL statement at cursor and show results.

:SqlLensRunAll                                              *:SqlLensRunAll*
    Execute all SQL statements in the buffer.

:SqlLensDB                                                      *:SqlLensDB*
    Open database picker — fetches available databases from
    the active connection and lets you switch dynamically.
    Supports search filtering and scrolling.

:SqlLensReport                                              *:SqlLensReport*
    Generate HTML report for all queries.

:SqlLensTables                                            *:SqlLensTables*
    Browse tables/collections in the current database.
    Select a table to generate a preview query
    (e.g. SELECT * FROM table LIMIT 50).

:SqlLensHistory                                            *:SqlLensHistory*
    Browse previously executed queries with preview pane.
    Default filter: current connection + database.
    Press <Tab> to cycle filter modes:
      1. Current connection + database
      2. Current connection (all databases)
      3. All connections
    Select a query to re-run it on the active connection.
    History is persisted to disk across Neovim sessions.

:SqlLensSaveConn                                          *:SqlLensSaveConn*
    Save the current active connection as a bookmark.
    Bookmarks are stored in ~/.local/share/nvim/sql-lens-bookmarks.json
    and auto-loaded alongside config connections on startup.

:SqlLensExport {fmt}                                      *:SqlLensExport*
    Export the last query result to a file.
    Supported formats: csv, json, md (markdown).

Result buffer keymaps (inside the result split):
    E           Open export format picker
    ec / ej / em    Export to CSV / JSON / Markdown
    ] / [       Next / previous page (for large results)
    q           Close result panel

CONFIGURATION                                               *sql-lens-config*

Default configuration: >lua

  {
    trigger = {
      on_write    = true,
      on_change   = true,
      debounce_ms = 500,
      min_length  = 10,
    },
    display = {
      mode          = "virtual",  -- "virtual" | "float" | "sidebar"
      virtual_prefix = "󰋼 ",
      show_cost     = true,
      show_rows     = true,
      show_warnings = true,
    },
    thresholds = {
      cost_warn     = 1000,
      cost_error    = 10000,
      seq_scan_warn = true,
    },
    history = {
      max_entries = 200,   -- max entries to keep
      max_days    = 7,     -- auto-delete after N days
    },
    keymaps = {
      toggle      = "<leader>sq",
      explain     = "<leader>se",
      show_detail = "<leader>sd",
      connect     = "<leader>sc",
      run         = "<leader>sr",
      run_all     = "<leader>sR",
      pick_db     = "<leader>sD",
      explore     = "<leader>st",
      history     = "<leader>sh",
      report      = "<leader>sH",
    },
  }
<

==============================================================================
CONNECTIONS                                            *sql-lens-connections*

Connections can be configured in setup(), .env files, or project-local
.sql-lens.lua files. See CONNECTION_GUIDE.md for full documentation.

The `dbname` field is optional for MySQL, PostgreSQL, and SQL Server.
If omitted, you will be prompted to pick a database after connecting.
Use :SqlLensDB or <leader>sD to switch databases at any time.

Supported databases:
- PostgreSQL (psql)
- MySQL / MariaDB (mysql)
- SQL Server (sqlcmd)
- SQLite (sqlite3)
- MongoDB (mongosh)
